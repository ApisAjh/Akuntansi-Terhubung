# 📖 About

Financial Accounting System is a web-based accounting application inspired by professional accounting software such as **MYOB** and **Accurate**.

The application helps users manage accounting transactions, generate financial reports, and maintain balanced financial records based on the accounting equation:

> **Assets = Liabilities + Equity**

Designed for:

- Small Businesses
- Personal Businesses
- Students
- Accounting Learning
- Financial Administration

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Install dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```
